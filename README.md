  The Event Tracking App is a powerful tool for scheduling and reminders that perfectly integrates into day-to-day life. It fits any lifestyle and simplifies work, school, and home life. Whether users are busy professionals, students, or personal organizers, the Event Tracking App offers a single destination to stay on top of their schedule and track all events. 
  To support user-centered design, three main screens were needed: login/sign-up, a grid to display database information, and an SMS notification screen. Each implemented screen follows best practices, including simplicity and common navigation patterns, and focuses on user experience. 
   I approach developing an application by breaking a big project into smaller parts until I can identify the separate and reusable modules that can be implemented. I adhere to an iterative development approach, implementing small parts and conducting frequent testing. I keep the logic separated, for example, database, repository, controller, and UI layers. Code refining is also an essential part of my development process.
